# monkey-multilayer-network
Interactive controls
- Rotate, pan, and zoom the three-dimensional network.
- Click a layer name in the legend to show or hide that complete layer.
- Use the edge-threshold menu to filter weak edges.
- Hover over nodes and edges to view layer-specific values.
- Click an OMU node to highlight that OMU across all three layers.
- Click the same OMU again, double-click the plot, or change the threshold to reset highlighting.
- Use the Plotly camera button to download a PNG from the current interactive view.
